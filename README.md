# منة المنان — تفسير القرآن الكريم

مستودع تطبيق «منة المنان» (قارئ القرآن وتفسيره، خمسة أجزاء).

**حالة النشر:** تم إعداد نسخة محسّنة واختبارها محليًا، وتسليم ملف ZIP الكامل في المحادثة. ملفات التطبيق نفسها لم تُرفع بعد إلى هذا المستودع.

## إكمال رفع النسخة المعدّلة

1. نزّل ملف **منة_المنان_نسخة_محسنة.zip** من المحادثة وفكّ ضغطه.
2. انسخ **محتويات المجلد المستخرج** إلى جذر هذا المستودع (وليس ملف ZIP نفسه).
3. احفظ التغييرات في فرع `main`. يحتوي الأرشيف على `index.html` و`book/` و`fahrst/` و`search-index.json` وملفات الخطوط والأيقونات والاختبارات.
4. لتفعيل الموقع: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## فحص المشروع بعد الرفع

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -p 'test_*.py' -v
node tests/test_search_worker.cjs
```

يعمل التطبيق عبر خادم HTTP(S) وليس فتح `index.html` مباشرة بنمط `file://`. الواجهة عربية وتخزّن بيانات المستخدم محليًا دون خادم.
