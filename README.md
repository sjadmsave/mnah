# منة المنان — تفسير القرآن الكريم

تطبيق ويب عربي مجاني لقراءة خمسة أجزاء من كتاب «منة المنان» والبحث فيها دون خادم أو حساب مستخدم، مع دعم تثبيت PWA والعمل دون اتصال بعد اكتمال التخزين المؤقت.

## الوظائف

- قارئ بخيارات الخط والتباعد والمظهر، واستئناف الصفحة وموضع التمرير.
- فهرس هرمي قابل للطي والتوسيع مع تصحيح إظهار العناوين الفرعية.
- محرك بحث خارج خيط الواجهة باستخدام Web Worker وفهرس `search-index.json` سابق البناء؛ يدعم التشكيل والهمزات والعبارات.
- المفضلة ومواضع القراءة؛ نسخ احتياطي محلي بصيغة JSON واستيراد مع التحقق من البنية.
- التثبيت والعمل دون اتصال باستخدام Service Worker بعد نجاح التحميل الأول.

## إضافات المرحلة الثانية (نسخة تطوير تجريبية)

- **فهرس السور:** مدخل «فهرس السور» من القائمة الجانبية، مع تصفية بالاسم. تُستخرج السور البالغ عددها 35 من سجلات `kind: سورة` في الفهارس الموثقة؛ لا تُستنتج أسماء سور أو أرقام آيات غير موجودة في البيانات.
- **روابط صفحات مباشرة:** مثال `#book=book2&page=49` على رابط التطبيق؛ تنسخ من زر «مشاركة» أثناء القراءة. رقم الصفحة يبدأ من 1، والروابط خارج الحدود تُتجاهل.
- **اقتباس موثق:** حدد نصًا، ثم اختر «نسخ مع المرجع» لإضافة عنوان الجزء ورقم الصفحة ورابط مباشر.

هذا **فرع تطوير وليس نسخة إنتاجية معتمدة**؛ يلزم اختبار ميزاته الجديدة قبل دمجها في `main`.

## التشغيل محليًا

يشترط العمل عبر `http://localhost` أو `https://` (وليس فتح `index.html` باستخدام `file://`) ليعمل البحث وPWA بشكل صحيح.

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`.

## الاختبارات

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -p 'test_*.py' -v
node tests/test_search_worker.cjs
node tests/test_research_tools.cjs
node --check research-tools.js
node --check search-worker.js
```

إذا عدّلت أحد ملفات `book/*.htm` أعد بناء الفهرس:

```bash
python build_search_index.py
```

ثم غيّر رقم نسخة ذاكرة التخزين المؤقت `CACHE_NAME` في `sw.js` قبل النشر.

## النشر على GitHub Pages

ارفع **محتويات هذا المجلد إلى جذر المستودع** مع المحافظة على المسارات `book/` و`fahrst/` و`font/` و`icons/`. ثم من إعدادات المستودع اختر **Pages → Build and deployment → Deploy from a branch → main / (root)**. يؤدي استخدام المسارات النسبية إلى دعم النشر من المسار الفرعي للمستودع.

## خصوصية البيانات

المفضلة والإعدادات محفوظة داخل المتصفح على جهاز المستخدم. لا توجد خدمة خلفية تجمع بيانات القراءة، ولا يتم إرسال النسخ الاحتياطية إلى خادم.

## حدود الإصدار

- لا يتضمن حسابات أو مزامنة سحابية أو مساعدًا قائمًا على الذكاء الاصطناعي.
- بعض وظائف التحديد المخصص قد تختلف بحسب الجهاز والمتصفح؛ التحديد الأصلي هو الافتراضي.
- الاختبارات المتضمنة تتحقق من اتساق الملفات ومنطق محرك البحث. يلزم أيضًا اختبار PWA وتجربة اللمس عمليًا على Android وiOS قبل الإطلاق العام.
> ملاحظة: ملفات المصدر الكاملة والكتب ما زالت ضمن حزمة ZIP التي سُلّمت للمستخدم، وليست منشورة بعد في هذا المستودع.
